# 🌍 Travel Explorer - Docker Website

A simple responsive travel website built using HTML, CSS, and JavaScript,
and containerized using Docker and Nginx.

## 📌 Project Description

Travel Explorer is a beginner-friendly travel website created for
internship training and learning purposes.

The project demonstrates how to:

- Build a static website
- Create a Docker image
- Run a Docker container
- Serve a website using Nginx
- Use Docker Compose
- Use Docker volumes and networks
- Manage the project using Git and GitHub

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Docker
- Docker Compose
- Nginx
- Git
- GitHub
