# AI Resume Builder

A simple and responsive Resume Builder created using HTML, CSS, and JavaScript with Vibe Coding.

## Features

- Create a professional resume
- Live resume preview
- Professional summary generator
- Education, skills, projects, and experience sections
- Save resume using LocalStorage
- Load saved resume
- Clear resume data
- Print or download resume
- Responsive design for mobile and desktop
- Client-side validation

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

How to Run
1. Clone or download the project

Open the project folder in VS Code.

2. Start the local server

Open PowerShell or Git Bash inside the project folder and run:

python -m http.server 5500
3. Open the application

Open your browser and visit:

http://localhost:5500
How to Use
Enter your name, email, and phone number.
Enter your education details.
Enter your skills.
Enter your projects.
Enter your work experience.
Click Generate Summary.
Click Generate Resume.
Click Save Resume to store your information.
Use Load Resume to restore saved information.
Use Print / Download to print or save the resume as a PDF.
